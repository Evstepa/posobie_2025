Инструкция
  • Выберите один из вариантов в каждом из 5 вопросов;
  • Нажмите на кнопку "Показать результат";
  • Скрипт не покажет результат, пока Вы не ответите на все вопросы;
  • Загляните в окно рядом с номером задания. Если ответ правильный, то там (+). Если Вы ошиблись, там (-).
  • За каждый правильный ответ начисляется 1 балл;
  • Оценки: менее 2.5 баллов - НЕУДОВЛЕТВОРИТЕЛЬНО, от 2.5, но менее 3.75 - УДОВЛЕТВОРИТЕЛЬНО, 3.75 и менее 5 - ХОРОШО, 5 - ОТЛИЧНО;
  • Чтобы сбросить результат тестирования, нажать кнопку "Сбросить ответы";
  1. Выберите правильную форму:
    программное обеспечение
    программной обеспечений
    программные обеспечения
    программная обеспечения

  2. Выберите правильную форму:
    системы программы
    системные программирования
    системы программирования
    систематическое программирования

  3. Выберите правильную форму:
    исполняемый файл
    исполняемая файла
    исполненный файл
    исполняющий файл

  4. Выберите правильную форму:
    дерево каталоги
    дерево каталогов
    дерева каталога
    дерево каталог

  5. Выберите правильную форму:
    исходный коды программы
    исходный код программа
    исходные коды программов
    исходный код программы
